# Known Issues Tracker

## Purpose

Track launch-impacting issues with explicit severity and ownership.

## Severity Rules

| Severity | Launch Impact |
| --- | --- |
| Critical | Blocks launch |
| High | Blocks launch unless accepted by release owner |
| Medium | Can launch with mitigation |
| Low | Does not block launch |
